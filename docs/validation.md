# 验证范围

v0.1.0，2026-10-12。本机 macOS、Python 3.14。脚本只依赖标准库。

## 可复现脚本检查

在项目根目录运行：

```bash
python3 -m unittest discover -s tests -v
```

9项检查覆盖四种模式的空白初始化、非空目录保护、重复初始化保护、无写入预览、Git仓库与worktree边界、符号链接路径、完整安装后独立初始化、已有技能保护、运行目录的默认Git排除。

这些检查验证文件行为，不验证模型访谈质量或真实成长效果。当前9项本机通过；Windows和Linux真机未验收。

## 发布检查

技能命名与frontmatter、内部链接、分发文件白名单、完整ZIP解压及逐文件SHA-256应在发布时检查。结果随发布记录保存，不从“文件存在”推断已上传或已被用户采用。

## 仍需工具内试用

- Codex／Claude Code的新会话发现与自动触发。
- 访谈是否简洁，首个真实成果是否符合本人标准。
- 跨会话检索、纠错、删除与共享行为，使用 [验收场景](../evals/scenarios.md)。
- 长期使用能否减少重复解释、积累工作成长证据或帮助生活行动。

自动化脚本通过、人工静态审阅、模型行为通过、用户使用有效是不同状态。
