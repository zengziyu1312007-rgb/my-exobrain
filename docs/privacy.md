# 数据与使用边界

公开代码、技能安装目录、个人实际记录目录是三个位置。请把个人外脑放在公开源码和公司共享目录之外。

## 附带脚本做什么

- install.py 复制本地完整技能，检查相同内容，不下载、不联网、不替换不同的旧版。
- init_brain.py 只生成空白目录和规则，不读取其他资料、不调用模型、不创建 Git、不上传。
- 初始化拒绝非空目录、Git 工作区和符号链接路径；生成忽略全部实际文件的 `.gitignore`，仅 `.gitignore` 自身可被常规暂存。
- 这些是防误操作措施，不能阻止强制 git add、另行复制、云盘同步或工具访问。

## AI 助手使用文件时

读取内容可能被所用模型服务处理，具体取决于产品、账户与设置。本项目不提供加密、模型服务端删除、身份鉴权或企业权限隔离，也不保证“只有你和 AI 能看到”。

首次约定读取路径、可以保存的类别、只聊不记类别和分享范围。允许范围内直接积累，新范围再确认。工作中组织拥有的原件、客户信息和第三方私人资料需有相应使用权限；可以只存脱敏经验与原系统引用。

## 纠错、撤回与分享

你可以纠正背景、暂停记忆或要求删除具体记录。助手需检查正文、索引、摘要和可控导出；日志不重复被删内容。旧备份、Git 历史、其他人副本与服务端内容可能不在助手控制内，应说明实际范围。

分享时单独生成获准材料，不把整个个人外脑打包发出。提交 Issue、PR 或求助截图时使用虚构／脱敏内容，不提交真实日记、公司原件、凭证或个人外脑 ZIP。
