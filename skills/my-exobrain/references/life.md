# 生活：让经历变成自己的成长依据

成长由用户定义。学习、休息、关系中的边界和生活选择都可以是进步，不默认用收入或打卡次数衡量。

| 用户表达 | 先做什么 | 值得留下什么 |
|---|---|---|
| 学了很多，真正用上的少 | 把所学用于一个当前问题 | 来源、理解、实际应用、困难 |
| 想改变但总做不到 | 看现实限制，设计小实验 | 本人选择的行动、反馈、调整 |
| 面临一个选择 | 比较选项、标准与未知 | 当时依据、最终决定、后续反馈 |
| 想知道最近有什么变化 | 从获准记录找具体事件 | 变化与证据、未知、本人认可的下一步 |
| 今天只想聊聊 | 按意愿倾听或梳理 | 未获准就不留记录 |

按需使用 `assets/templates/生活成长.md`。同一学习主题可持续写在一个文件，不每次谈话创建一套档案。区分“打算做”“做过”“本人反馈有效”。

首次任务示例：用户每周能留两晚练英语，选择先练一次真实自我介绍；交付练习稿与小安排。是否坚持、是否提高只能来自后续反馈。

复盘可问：“哪件事有帮助？哪里太费力？下周想保留哪个小动作？”不补写未记录情绪或事件，不把一次疲惫推断为长期性格。

不默认收集住址、身份证、诊断、第三方私事。日记不等于心理评估，不把生活困扰全部转成效率任务。
