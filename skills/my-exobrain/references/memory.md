# 记录、检索与纠错

## 内容落点

| 内容 | 正本 | 更新 |
|---|---|---|
| 协作与保存范围 | 00_入口/协作约定.md | 本人明确变更时 |
| 获准背景 | 00_入口/我的背景.md | 事实改变时，注明来源 |
| 当前事项 | 00_入口/当前重点.md | 有进展更新；结束项移出摘要，主题记录保留 |
| 经验与资料 | 生活／工作主题文件 | 去重、保留依据和条件；入口只做摘要与索引 |
| 纠错与状态 | 00_入口/确认与变化.md | 记变化及受影响文件，不重复敏感正文 |

每条实际知识保留：内容、来源、记录日期、状态、适用范围。用户明确表达写“用户自述”；文档注明文件及位置；AI分析标“判断／依据”。决定加生效时间，未知不编。

## 保存

获准类别内：找已有主题 → 去重 → 写正本 → 更新索引／当前重点 → 回报文件。不要逐条重复确认，不默认保存原始对话全文。

首次可约定：“本地保存工作任务、进展和方法；生活闲聊只用于当前对话；不导入公司客户原件。”记允许类别、排除类别、读取路径、分享范围。后来明确“这一条记下来”可授权该条，不扩展成永久全量记录。

## 检索

规则与索引 → 当前重点 → 相关主题 → 必要时原始依据。不全量加载日记，不跨组织或他人空间。问现在用有效记录，问过去再查历史。同一来源多次转载不增加独立证据。

## 冲突与纠错

比对象、日期、生效时间和来源。本人明确改安排，更新当前正本，旧记录标被替代；来源不清保留分歧，不擅选。修复受影响的摘要、索引和方法。

## 复盘

用户请求时回顾原目标、实际发生、证据、反馈、可保留方法、下一次调整。资料不足就说不足；没记录不表示没发生。每周复盘不自动创建定时任务，只有明确要求且工具可用时才设置。

## 删除与暂停

“不再记”：停止后续持久化，更新规则，不表示旧内容已删。

“删除这条”：目标明确就执行授权删除，检查正文、摘要、索引、可控导出和缓存，不把正文写进删除日志。不可逆工具步骤遵守环境要求。Git历史、备份和服务端副本可能仍保留，说明实际范围，不承诺全网遗忘。恢复旧备份也遵守删除要求。

## 方法保留

有具体触发、真实输入、实际产物和检查标准再整理方法。保留适用条件、失效情况、验证日期；不把一次成功写成普遍保证。改进不能放宽授权。
