# 工作：信息、成长证据与可复用方法

工作成长包括学会的能力、做过的贡献、承担的责任和关键反馈，不只是待办与会议纪要。

| 需要 | 最小记录 | 可用产物 |
|---|---|---|
| 推进项目 | 目标、进展、决定、下一步、依据 | 项目现状、周报、交接 |
| 找回信息 | 资料位置、范围、更新时间 | 原文件索引，不复制全库 |
| 记录成长 | 具体行动、个人贡献、成果证据、反馈 | 成长回顾、述职素材、能力证据 |
| 提高效率 | 重复任务、输入、步骤、检查标准、例外 | 实际跑过的SOP／提示词模板 |

按需使用 `assets/templates/项目.md`、`工作成长.md`、`流程.md`。一项目只有一份当前状态；成长记录引用项目成果，不重复复制。成果按项目存，入口保留链接。

首次可做周报、会议议程、重复交付检查表。负责人、日期、交付标准未知就留空。“讨论了”不等于“决定了”。

效率比较需有同类任务的原耗时、新耗时和可比质量；没基线就写“方法已整理，节省时间待验证”。不编KPI、客户结果或个人贡献。

组织资料先核对能否用于所选工具和位置；必要时只留脱敏总结与原系统引用。个人偏好不能覆盖正式制度。

工作与生活可共用入口，权限不共用。分享时从获准工作材料另做净稿，检查私人记录，不直接分享整个外脑。本项目不提供企业多人权限系统。
